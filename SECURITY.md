# Security Policy

## Supported Versions

This project currently follows the active development version in the repository.

## Reporting a Vulnerability

If you discover a security issue, please report it responsibly and do not create a public issue with sensitive details.

Include the following information when reporting:

- A clear description of the issue.
- Steps to reproduce the issue.
- Affected file or component names.
- Any known impact or risk.

## Security Guidelines

- Do not commit secrets, passwords, or API keys.
- Review changes to `contributors.json` carefully before merging.
- Validate GitHub workflow changes before enabling them on the main branch.
- Keep contributor contact information accurate and limited to what the project requires.
